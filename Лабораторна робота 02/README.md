# Лабораторна робота №2. Програмування числових послідовностей та циклічних процесів

Ознайомтесь з [методичними вказівками](LABWORK2_instructions.md) та знайдіть там таблицю з індивідуальними варіантами. Варіанти розподіляє викладач, таблицю з розподілом має бути прикріплено у завданні в Teams.

Приклади оформлення алгоритмів наведено у вказівках та в форматі .drawio (`lab_02_example.drawio`).

Після виконання завдання скористайтесь наведеним шаблоном для оформлення звіту (`Шаблон звіту ЛР 02.docx`). Звіт треба прикріпити до завдання у Teams.
