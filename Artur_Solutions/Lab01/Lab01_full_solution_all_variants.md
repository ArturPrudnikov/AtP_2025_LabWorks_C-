# 2. Важливі вимоги лабораторної роботи

- У програмі ЛР №1 не потрібно використовувати if, switch, for, while або do while.

- Для кожного варіанта розрахунок виконується двічі: спочатку зі змінними типу int, потім зі змінними типу float.

- Для функції sqrt() підключається бібліотека \<cmath\>.

- Перший розрахунок з int може відкидати дробову частину. Це нормальна демонстрація особливостей цілочисельних типів.

# 3. Короткі теоретичні відомості

**Структура програми:** Типова програма C++ містить директиви \#include, за потреби using namespace std;, головну функцію int main(), оголошення змінних, оператори введення/обчислення/виведення та return 0;.

**Введення та виведення:** cin використовується для введення даних з клавіатури, cout — для виведення інформації. Оператори \>\> та \<\< передають дані відповідно у програму та у вихідний потік.

**Тип int:** Зберігає цілі числа. При цілочисельному діленні дробова частина відкидається, наприклад 5 / 2 дає 2.

**Тип float:** Зберігає дійсні числа з дробовою частиною. Наприклад, 5.0f / 2.0f дає 2.5.

**Бібліотека \<cmath\>:** Містить математичні функції, зокрема sqrt(), sin(), cos(), tan(). У цій роботі sqrt() потрібна для формули Герона, теореми Піфагора та обчислення твірної конуса.

**Лінійний алгоритм:** Алгоритм, у якому команди виконуються послідовно одна за одною без розгалужень і циклів. Саме такий алгоритм використовується у ЛР №1.

**Формули:** P = a+b+c; p = P/2; S = √(p(p−a)(p−b)(p−c)) (формула Герона)

1\. Ввести сторони a, b, c.

3\. Обчислити півпериметр p = P/2.

4\. Обчислити площу за формулою Герона.

5\. Вивести P та S.

6\. Повторити для float-версії.

### Код C++

pFloat=aFloat+bFloat+cFloat; halfPFloat=pFloat/2.0f;  
sFloat=sqrt(halfPFloat\*(halfPFloat-aFloat)\*(halfPFloat-bFloat)\*(halfPFloat-cFloat));  
cout\<\<"Perimeter = "\<\<pFloat\<\<"\nArea = "\<\<sFloat\<\<"\n";  
return 0;  
}

# 6. Відповіді на типові контрольні запитання

**Що таке C++?**

C++ — компільована мова програмування загального призначення, що підтримує процедурний, об’єктно-орієнтований та інші стилі програмування.

**З чого починається виконання програми C++?**

З функції main(). Вона є точкою входу в програму.

**Для чого потрібен \#include \<iostream\>?**

Він підключає засоби стандартного введення та виведення, зокрема cin і cout.

**Для чого потрібен \#include \<cmath\>?**

Для використання математичних функцій, наприклад sqrt(), sin(), cos(), tan().

**Що означає using namespace std;?**

Дозволяє звертатися до об’єктів стандартного простору імен без префікса std::, наприклад cout замість std::cout.

**Що таке змінна?**

Іменована область пам’яті, у якій зберігається значення певного типу.

**Чим int відрізняється від float?**

int зберігає цілі числа, а float — дійсні числа з дробовою частиною.

**Що відбудеться при 5 / 2 для int?**

Результат буде 2, тому що дробова частина при цілочисельному діленні відкидається.

**Як отримати 2.5 при діленні 5 на 2?**

Хоча б один операнд має бути дійсного типу: 5.0f / 2.0f або 5.0 / 2.0.

**Для чого використовується cin?**

Для зчитування значень із стандартного потоку введення, зазвичай з клавіатури.

**Для чого використовується cout?**

Для виведення тексту та значень змінних у консоль.

**Що робить оператор = ?**

Виконує присвоєння: записує значення правої частини у змінну зліва.

**Що робить sqrt(x)?**

Повертає квадратний корінь з x. Аргумент має бути невід’ємним для звичайних дійсних обчислень.

**Що означає return 0; у main()?**

Повідомляє операційній системі, що програма завершилася успішно.

**Чим компіляція відрізняється від запуску?**

Під час компіляції вихідний код перетворюється на виконуваний файл; під час запуску цей файл виконується процесором.

**Що таке лінійний алгоритм?**

Послідовність дій, що виконується зверху вниз без розгалужень та повторень.

**Чому у ЛР №1 немає перевірки помилкових даних через if?**

За умовами роботи розгалуження та цикли ще не вимагаються; вони вивчатимуться у наступних лабораторних роботах.

**Навіщо тестувати програму?**

Щоб перевірити правильність формул, введення/виведення, роботу з різними значеннями та побачити обмеження використаних типів даних.

# 7. Загальний висновок

Під час виконання лабораторної роботи було розглянуто структуру програми C++, підключення стандартних бібліотек, оголошення змінних типів int і float, введення даних за допомогою cin, виведення за допомогою cout, арифметичні операції та функцію sqrt() з бібліотеки \<cmath\>. Було реалізовано лінійні алгоритми для обчислення характеристик геометричних фігур та підготовлено тестові набори. Практично показано відмінність між цілими та дійсними типами даних: int може втрачати дробову частину, тоді як float дозволяє виконувати обчислення з дробовими значеннями.
